# Step 1 — animation video creative handoff

Use [GROK_ANIMATION_VIDEO_BRIEF.txt](GROK_ANIMATION_VIDEO_BRIEF.txt) as the current Grok instruction file. Upload it into the existing songwriting project after the approved style and lyric pass.

Grok uses text to choose the song, animation theme and proposed lyric passage. Its result is one filled, ready-to-paste prompt for a Claude animation conversation. The user supplies the exact recording directly to Claude.

The finished animation targets 35–40 seconds and has a hard maximum of 45 seconds. Claude establishes the audio excerpt, timing and a complete short dramatic arc. Stills, the timed board and adjacent-frame strips support planning. The first playable candidate is the complete target-duration video.

Set up Claude with the [project context pack](claude-animation-project-context/00_SETUP_AND_UPLOAD_GUIDE.txt), paste Grok's returned prompt into a new project conversation, and attach the master recording and approved lyrics there.
