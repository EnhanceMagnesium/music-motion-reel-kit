GAPS THAT A NEW REPOSITORY CAN ADDRESS

A. VERIFIED LYRICS-TO-AUDIO CUES — HIGHEST PRIORITY
Existing beat grids, energy events and metadata do not verify the identity and onset of a sung word. A useful timing resource must accept the approved words, preserve the exact recording, expose word/phrase intervals and support correction. The desired production record stores source start/end, video-local start/end, lyric identity, alignment method, evidence status and review notes. Alignments remain hypotheses until checked against the supplied performance.

A1. WhisperX — recommended first automated alignment candidate
https://github.com/m-bain/whisperX
https://github.com/m-bain/whisperX/blob/main/README.md
Its official source documents word-level forced alignment and CPU int8 execution, as well as GPU operation. This makes it a practical candidate for the local Mac without assuming CUDA availability. Keep the approved lyrics as authority and inspect/correct the alignment output; use the supplied text/segments rather than accepting an automatic transcription as the displayed lyric.
Fit: create a reviewed cue map consumed by the existing renderer.
Boundary: speech-oriented models do not establish accuracy on this sung performance; singing, accompaniment, repeated phrases and sustained syllables need validation. Model downloads, language-specific aligners and environment dependencies must be measured during a later authorized setup. Speaker diarization is outside this song task.
Code license recorded by current repository metadata: BSD-2-Clause. Model weights retain their own terms. Repository is active/unarchived at audit.

A2. SOFA — specialist fallback for singing
https://github.com/qiuqiao/SOFA
https://github.com/qiuqiao/SOFA/discussions/31
This project specifically targets singing voice. It supports aligned audio/text pairs, confidence output and annotation formats including TextGrid. Its README requires a checkpoint and phoneme/dictionary or grapheme-to-phoneme configuration; English model sharing is documented separately.
Fit: investigate if the first alignment route fails on singing and a suitable English checkpoint is available.
Boundary: the source instructions use an older Python environment; local Mac compatibility, checkpoint licensing and language configuration need specific verification. Exported phoneme intervals require a deliberate conversion to this project's word/phrase cues. Source claims of better performance are author claims, not a measurement on His Line.
Code license metadata: MIT. Repository unarchived at audit. Keep checkpoint selection and model terms separate from code licensing.

A3. python-audio-separator — optional vocal analysis copy
https://github.com/nomadkaraoke/python-audio-separator
https://nomadkaraoke.github.io/python-audio-separator/
Provides local vocal/instrument separation through pretrained models, with CPU and Apple Silicon paths documented. Use it when accompaniment prevents reliable lyric inspection or alignment.
Fit: derive a clearly labeled vocal-only analysis file and retain its relation to the exact master.
Boundary: separation can introduce artifacts. Preserve the selected Suno master as the production soundtrack; compare any derived timing against the original mix. Model and dependency selection has a separate setup/resource cost. Its current dependency requirements must be checked on the Mac before adoption.
Code license metadata: MIT. Active/unarchived at audit; inspect each selected model's provenance and terms.

B. CORRECTABLE CUE REVIEW — HIGH PRIORITY
B1. wavesurfer.js — selected browser component for an eventual cue-review tool
https://github.com/katspaugh/wavesurfer.js
https://wavesurfer.xyz/docs/plugins/
Waveform playback plus Regions/Timeline plugins can support a local review interface with draggable lyric/event boundaries. The project-specific adapter would load the original audio and existing cue JSON, display evidence status and save corrected times in the established source/video time bases.
Fit: reusable human-review UI alongside the current renderer; keep the rendering engine unchanged.
Boundary: waveform display and draggable regions are review controls. They do not perform lyric recognition or establish verified timing by themselves. This editor is not currently integrated.
Code license metadata: BSD-3-Clause. Active/unarchived at audit.

B2. Audacity — immediate desktop alternative to building a review UI
https://github.com/audacity/audacity
https://manual.audacityteam.org/man/importing_and_exporting_labels.html
The established label-track workflow exports text timestamps. It can provide reviewed phrase/word anchors with a small label-to-cue conversion step, useful for one short recording before investing in a custom editor.
Fit: optional independent desktop tool, using its stable release's label import/export support.
Boundary: verify the installed version's supported export behavior; development/alpha UI may differ. Preserve the original recording and export label data separately. This is a tool-use option, not an instruction to embed its engine in our JavaScript source.
Current source identifies GPLv3. Check dependency notices if copying application code; this recommendation is for using the standalone tool.

C. PORTABLE TYPOGRAPHY — HIGH PRIORITY
C1. Google Fonts source repository — selected font source
https://github.com/google/fonts
https://github.com/google/fonts/blob/main/README.md
Provides actual family files with metadata and license records. Choose the approved face and necessary weights/glyphs, save them locally, record the family license and hash the files used by the render.
Fit: close the shared library's reliance on remote Google Fonts CSS and provide repeatable offline appearance. Existing His Line font placeholders are already local, so the gap is the approved design face and reusable-library portability.
Boundary: fonts have family-specific licenses; the repository does not carry one blanket font license. Select only needed families, not the entire multi-gigabyte collection. A chosen serif or sans face still requires the user's design direction and phone-scale review.

C2. OpenType.js — available source, conditional typography helper
https://github.com/opentypejs/opentype.js
Supports font parsing, glyph paths and metrics in JavaScript. Useful if a selected shot needs outlines for printing, masks or deliberate type deformation.
Local source already exists at:
source-library/raw/github/lemomo-ai/lemo-opuscar/b65efe6ea393fdc71212898ea4c57c754cfefa46/styles/spy-titles/demo/vendor/opentype.min.js
Its license notice is beside it as opentype-LICENSE.txt. Check that vendored version against the required feature before adopting a newer package.
Fit: reuse this acquired source when the shot requires glyph geometry. Ordinary editable text can remain on the current canvas/text path.
Code license metadata: MIT. Upstream unarchived at audit.

D. VISUAL REGRESSION AND TRANSFORMATION HELPERS — CONDITIONAL
D1. pixelmatch
https://github.com/mapbox/pixelmatch
Compares rendered pixel arrays and can make changes in fonts, compositing or a deterministic frame visible during authorized regression review.
Fit: a later small integration check around fixed representative frames when visual review is authorized.
Boundary: pixel agreement is not a test of attractive animation, narrative development or musical expression. Reference frames, stable seeds and a controlled browser environment are prerequisites; current stage does not authorize generating those frames.
Code license metadata: ISC. Active/unarchived at audit.

D2. Flubber
https://github.com/veltman/flubber
Produces shape interpolators evaluated at a normalized progress value. That maps naturally to a pure time-based scene when a chosen motif needs a genuine shape transformation.
Fit: optional single-shot helper for a named transition or object transformation.
Boundary: holes and multi-part paths have limitations; complex lettering requires care. Last recorded push is 2022; this is a mature, older codebase rather than an actively developed dependency. Retain existing hand-authored paths when they already express the shot.
Code license metadata: MIT; unarchived at audit.
