ANIMATION REFERENCE CRAFT GUIDE — FROM SIX REFERENCES TO NATIVE 4:5 OR 9:16 SONG COMPOSITIONS
Prepared 2026-10-25 in the original kit. Documentation only: no production code, media, audio or dependency was changed. This is the single detailed reference-to-technique source; routers only point here.

HOW TO USE
Read sections 1-2 when choosing a visual direction for a new finished song, section 3 when selecting source mechanisms, section 4 as the per-song workflow, and section 5 for what is not yet known. The six videos are references for CRAFT (staging, image-making, motion, camera, typography, pacing). Do not copy their footage, layouts, characters, wording, stories or palettes. For each new song, choose either 4:5 (1080×1350) or 9:16 (1080×1920) based on its own visual direction, explain the choice before storyboarding, and compose natively for that frame. His Line is one prior example, not a default.

EVIDENCE LABELS USED BELOW
[S] observed in the sampled one-second stills (I viewed the 13 contact sheets; thumbnails about 190 px wide). [I] inferred from stills or from source code; plausible, not observed. [U] unverified / unknown.
What I could NOT do: play any MP4. The Read tool shows images, not video, and this pass did not extract new frames. So continuous motion, easing, transition timing, audio sync and anything shorter than one second are [U] for all six videos. Sheet cells are labelled with source seconds (0, 1, 2 ...); a range such as 43-49 s means those samples.

SHARED VISUAL PRINCIPLES (supported by two or more references) [S unless marked]
P1. One dominant focal element per beat; everything else supports it (A, C, D, F).
P2. Palette discipline: either one accent on near-black (B), one red on parchment (C), or a different single colour field per beat (E); colour state changes carry structure (A, E). These are palettes OBSERVED in those references, not palettes to adopt: borrow the discipline, never the colours.
P3. Type is image: staged on paths, planes, masks, inside shapes or growing letter by letter (B, E, F, D).
P4. Quantity made visible: counters, dot grids, percentage climbs (A, B, C, D).
P5. Reset beats between chapters: blank sample, flat colour, light-paper cut, title card (A, B, C, E).
P6. A recurring motif that develops (flame in D, ring pulse in A, the character in F, the fuse line in B).
P7. Section-level change of drawing mode matches lyric/narrative change (F, E, D).
P8. Opening restraint then escalation, ending on a calm card (A, B, D, F).
P9. Mixed material treatment (halftone, duotone, line art) makes unrelated sources feel unified (E, D, B).

2. CHOOSING AND TRANSLATING PRINCIPLES FOR A NEW SONG
======================================================================
SELECTION METHOD (use the song's own material; reference match is secondary)
1. Genre/mood: driving electronic/synth -> HUD/data grammar or kinetic type (A, B); intimate acoustic or storytelling -> paper/ink or illustrated rig (C, D, F); lyric-dense rap/pop -> lyric-as-environment (F) or collage (E); epic/ambient -> single evolving light motif (D).
2. Lyrics: pick the 1-3 nouns/verbs that can become images or counters; if the song counts, climbs or repeats, P4 fits; if it narrates, P7 fits.
3. Musical structure: map sections to beats (verse = quieter mode, chorus = revisited "stage" or full-colour state, drop/bridge = reset beat or colour flip). Derive the map from the song's own cues (evidence-labelled, see shared-animation-library cue-schema), never from a reference.
4. Choose up to 3 candidate treatments, state what each costs (sources, assets, fonts, risk) and recommend one.
5. Palette: Choose the palette from this song's recording, lyrics, brief, theme, narrative and visual treatment, and briefly explain the reasoning before storyboarding. Do not use Claude's brand orange merely because Claude is the assistant, and do not carry over a prior song's colors or a house palette as defaults; orange is allowed with a clear song-specific rationale. Make a reasoned, editable choice and record it in this song's plan and config; do not ask the user to pick swatches or routine palette options, and ask only if an essential input is missing or the decision has a material consequence that cannot be responsibly inferred. Give colors roles (ground, ink, focal accent, lyric/type treatment, secondary detail). Check contrast, hierarchy and readability in rendered work, and do not claim those checks passed before the images are reviewed. Reference palettes are evidence about those references, not required palettes; borrow craft and create this song's own color direction. Keep each song's palette in that song's folder and conversation; never promote one production's palette into a studio-wide template.
5. Keep treatment, timing, assets and theme independent of previous songs; reuse mechanisms, not imagery.

PER-SONG FORMAT SELECTION AND NATIVE COMPOSITION
Choose one frame before storyboarding:
- 4:5 at 1080×1350 when the song's visual direction benefits from a compact portrait field, a close focal hierarchy or less vertical separation.
- 9:16 at 1080×1920 when the treatment benefits from a taller vertical field, extended stacking or greater vertical camera travel.
These are compositional considerations, not fixed genre rules. Base the recommendation on the supplied song and intended use; explain its consequences for subject scale, hierarchy, type, camera, transitions and negative space. Record the ratio and exact PROJECT.width/height in that song's plan/config. The renderer's configurable dimensions do not automatically adapt authored scenes.

Compose for the selected canvas from the start; do not crop or resize a layout designed for the other ratio. Re-stage each focal element. Side-by-side panels may become deliberate vertical stacks, one-at-a-time panels or a different composition; choose what serves the image rather than following a formula. Rework wide motifs (timelines, bars, cities) only when a new arrangement remains legible and purposeful; radial, ring and reticle forms may fit either frame when staged accordingly.

For a song that uses archival footage, plan its timeline duration independently from its visible frame footprint and prominence. Keep footage selections and timing while letting original code-built subjects, settings, choreography, typography and transformations carry more of the visual story. Every footage-bearing scene needs meaningful code-authored action beyond a border, tint, caption or texture. Use `17_FOOTAGE_FRAME_FOOTPRINT_AND_CODE_ACTION.txt` for the per-shot plan and R14–R16 craft-resource decisions; it uses existing projects as code-reading evidence, not as art templates.

Use fewer words per line and size type for phone reading. Treat interface margins as a working assumption and confirm current platform requirements when they matter; exact safe-zone values were not checked in this guide. Check every scene and overlay, all frame edges and key text at the chosen dimensions and phone size. Do not claim either ratio has passed visual review without actual output review.

Use each song’s complete supplied master at its measured duration by default; choose a shortened excerpt only if the user explicitly requests one. References may be much shorter or longer than a song production: study their image craft and invent a song-specific visual arc across the full recording instead of compressing the song to fit a reference runtime. Preserve the master audio; changes to its duration require an explicit decision.

======================================================================
4. WORKFLOW FOR A NEW SONG
======================================================================
1. Intake: recording attached to the conversation, optional Grok brief (text-derived), lyrics. State which audio capabilities this session actually has.
2. Plan the visual arc across the complete supplied recording at its measured duration. Do not select a shortened excerpt unless the user explicitly requests it. Keep the original master untouched; record source and production time separately, and report any frame-quantization difference at export.
3. Choose treatment: section 2 method; compare up to three; recommend one; write the one-sentence rule set (song-specific palette with reasoning, motif, type behaviour, reset-beat plan, camera behaviour).
4. Select 1-3 mechanisms (section 3). For each: read the named files and the call path now, record repo/commit/path/symbol/dependencies/time model/licence, and label guidance vs source vs adapted vs integrated.
5. Specify a timed board: opening hook, development, strongest moment, ending; per-shot purpose; evidence-labelled cues; source-to-helper-to-shot traces.
6. Implement in the song's own production folder using the shared production shell (PROJECT.modules / PROJECT.scenes, cues, assets, fonts); add an adapter only for a named need; keep separate engines separate.
7. Use `07_QUALITY_REVIEW_AND_ACCEPTANCE.txt` as the canonical bounded review process. Keep source/config checks, browser readiness, risk-based stills, full-candidate playback with sound, audiovisual alignment and user creative acceptance separate; each media stage still requires its applicable authorization. Sparse reference stills describe only their sampled appearances and do not prove motion or sync.
8. Record accepted lessons in the song's checkpoint; carry mechanisms forward, not imagery.
