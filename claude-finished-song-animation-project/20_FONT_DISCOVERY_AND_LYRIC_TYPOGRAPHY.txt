# Song-specific font discovery and lyric typography

Purpose: choose typography that serves this song's story and remains readable in the finished frame. The agent makes routine type decisions and documents the evidence; no universal font, aesthetic or previous song is the default. Follow the song's brief and supplied lyrics. When no text is shown, record that decision and apply this workflow only to other meaningful text. If captions are selective, preserve permitted displayed words exactly and review the actual treatment; follow the active tool's requirements.

## 1. Establish needs before choosing

Read the supplied recording, approved lyrics and optional brief; distinguish actual listening from text-only inference. Note the emotional arc, setting, visual material, audience, native 4:5 or 9:16 frame, intended language/scripts, mixed-case needs, punctuation, diacritics and any desired in-scene emphasis. Identify roles: longer lyric lines, single emphasized words, title, credits or interface-like elements. Specify the story and readability needs of each role. The font search and shortlist inform storyboarding; actual song rhythm, display durations and cue timing remain evidence-labeled.

## 2. Discover candidates and verify source

Search existing authorized kit/font assets and song-provided fonts first, checking the exact file and terms. If they do not fit, research suitable typefaces from reputable foundry or catalog sources; Google Fonts is one possible source (https://fonts.google.com/ and https://developers.google.com/fonts). Do not assume all fonts on the internet share a license. Examine the actual family's license, version, distribution, attribution and video/font-file redistribution terms; distinguish rendering a video from sharing a font file. Open Font License fonts have their own conditions, including notices and restrictions on selling fonts by themselves: https://openfontlicense.org/open-font-license-official-text/. For paid, unclear or incompatible terms, use another suitable option or report the boundary; do not infer permission from availability.

Shortlist a proportionate set of candidates, normally two or three when useful; a well-supported single candidate or no displayed text can be appropriate. Search by the song's intended visual tone and actual requirements rather than a fixed list of genres or fonts. Compare candidates with the song's actual representative lines: short, long, mixed case, punctuation, unusual glyphs and difficult pairs. Record candidate family, foundry, source URL, exact files/version, license evidence, supported scripts/glyphs, available weights/styles, role, reason to keep or decline, and unresolved facts. Metadata or a catalog preview is not evidence of how the font looks in the actual film.

## 3. Choose and plan

Select the typeface and actual weight/style per role. One well-chosen family can serve several roles; use a separate expressive face only when it improves the story and hierarchy. A title or a large emphasized word may use a distinctive face while longer lyrical text benefits from a readable text face. Establish actual foreground/background placement, sizing, case, tracking, line spacing, line length, wrap rules, safe margins, reveal/full-visibility/exit timing and how text interacts with subjects and footage. Choose a fallback that contains missing characters if the preferred font lacks them; do not silently substitute glyphs or alter supplied words. Preserve the source recording and lyric copy.

Record the selection and actual evidence in `productions/<song>/research/FONT_SELECTION.md`; start from `repository-preparation/templates/FONT_SELECTION_RECORD_TEMPLATE.md`. A deliberate no-text choice gets a concise entry. Record why the chosen type fits this song, its role and actual implementation caller. User-facing creative options are not a routine gate. If an essential rights, glyph or access issue cannot be resolved with a suitable authorized fallback, report the precise boundary and continue independent work.

## 4. Implement in the shared Remotion route

Store the actual permitted font files under the song's configured `public/` directory, normally `public/fonts/`, with relevant license/notice and provenance in the song folder. Declare exact family, `src`, weight, style and optional unicode range through `PROJECT.fonts`, with `src` relative to the production root. Follow `shared-animation-library/remotion-runtime/README.md` and the existing scene contract. The shared runtime uses browser FontFace loading and waits for declared resources; verify the actual candidate and fallback behavior instead of assuming a declared name proves the selected file rendered. Avoid system-only fonts for a portable production unless use rights and availability are established; prefer reproducible local files. Respect project authorization for remote retrieval; a song production prompt may authorize free licensed font downloads but does not authorize package installs, paid fonts or credentials.

Use actual loaded font metrics for layout; avoid per-frame network fetches and nondeterministic asynchronous text measurement. If special implementation needs arise, consult Remotion's current documentation: https://www.remotion.dev/docs/flickering and https://www.remotion.dev/docs/fonts-api/. The latter describes an optional package; it is not a requirement to replace this kit's existing font loader or install a package. Declare all needed styles/weights and avoid fake bold or unintended substitution where it affects legibility.

## 5. Review and report

Use risk-based pre-export stills for representative longest/shortest lines, special glyphs, each distinct font/weight, background changes and emphasis states; include selective-caption or audible-only behavior if relevant. Inspect original images at full resolution and realistic phone-display size. Check exact supplied text, actual loaded font appearance, missing/replacement glyphs, script shaping and direction, contrast over the real backgrounds, line wrapping, clipping, safe margins, weight, spacing and visual hierarchy. Consider a 4.5:1 normal-text contrast ratio as a useful W3C reference where measurable, while judging moving/image backgrounds in context; do not claim WCAG conformance from a still or ratio alone (https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

Inspect meaningful reveal/full-visible/exit states; use authorized normal-speed playback with sound to assess dwell and alignment when possible. A plan, font manifest or one still does not establish actual loading on every frame, glyph correctness across all text, motion, sync or user acceptance. Check the encoded candidate as required by guide 07, report limitations, and use targeted evidence-based corrections. Record reviewed timestamps, output identity and results in the font record and song review. Promote only broadly verified technical lessons, not this song's font, palette or visual identity, into shared learning.
