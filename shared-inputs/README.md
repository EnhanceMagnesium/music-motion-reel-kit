# Song input folders

Create one folder per new song inside `shared-inputs/`. Put the finished recording, final lyrics and optional creative brief together, for example:

```text
shared-inputs/my-new-song/
  recording.m4a
  lyrics.txt
  brief.md
```

Use the recording's actual filename and format; lyrics or a combined lyrics/brief file may also have another name. Provide the song-folder path in the selected agent's launch prompt. Inputs already accessible locally do not need re-uploading. Other user-supplied paths or task attachments remain supported. Preserve original files, resolve ambiguity about the recording or lyric source with the user, and put song plans, working copies, scenes, evidence and outputs in the separate `productions/<song>/` folder. A brief is optional. Avoid overwriting existing work.
