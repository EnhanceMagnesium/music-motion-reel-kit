# Claude ordering and Prelinger item-evidence update — 2026-10-31

The Claude production prompt now orders intake, frame/palette and source discovery before the second-by-second storyboard and implementation. Listening is conditional on actual capability; lyric display explicitly includes none. Commons requests use the authorized operator contact documented in guide 15. The public sharing copy requires its own operator contact and does not embed another person's address.

Prelinger’s current FAQ says that some, but not all, films carry its Creative Commons Public Domain Dedication, and recommends checking specific items and contacting the archive for those without that dedication: https://www.panix.com/~footage/prelarch.html. General collection membership and user direction do not establish a third-party license. Existing allowlisted item-level rights continue to work. For selected Prelinger items whose fresh Internet Archive metadata has no item rights fields, an agent can record reviewed item-specific permission in song-local JSON and pass `--prelinger-evidence` to the downloader. The helper verifies collection identity, item identity, path containment and evidence structure, and records the evidence and unverified classification. It does not authenticate permission. Conflicting/explicit restrictions and missing evidence remain blocked.

Synthetic Node tests cover existing rights paths, valid reviewed evidence, source restrictions, missing evidence, wrong item, non-Prelinger collection and path checks. No song, actual footage, network download or render was performed for this change. User-authorized operator contact is retained only in the active local guide and must be passed in requests; the public repository uses an operator-supplied value. The helper is not a rights certification service.
