## Maintenance after every pass

Save each substantive pass report and evidence under its song folder, update that song's CHECKPOINT.md, and maintain this file whenever a verified general lesson is learned or invalidated. Existing entries may be refined with new evidence; preserve prior evidence and explain superseded conclusions. For each entry retain trigger/consequence, environment/source identity, evidence, cause/fix, verification, future application and limits. Promote safeguards to implemented only after code and evidence support that status. This obligation continues after the current pass.

## L15 — Scene-local time and cue rounding

Trigger: caption and cut tests disagreed with cue seconds by a frame. Cause: TimedLayer local time starts at the scene's rounded start frame (round(start x fps)), not at the exact cue; a scene-local cut time lands on the first local frame >= that time, and a caption appears on the first frame whose time >= its cue, so both can land up to one frame after the supplied second. Evidence: the failed run2 above (frame 17 = 0.708 s < cue 0.718 s) and the computed cut pairs in implementation_20261025/still_set_proposal.json (S04 612/613, S06 1041/1042, S07 1183/1184, S08 1404/1405). Future action: derive boundary and cut frames with the same rule, request stills one or two frames after a cue, and never describe a frame-rounded landing as sync with the sung audio.

## L22 — Technical traps found while building Chalk it up (2026-10-28, native Mac, Remotion 4.0.538)

Evidence root: `productions/chalk-it-up-white-wellbeing-the-spirit-of-the-west/` (song-specific creative choices stay there).

1. **SVG filter regions can erase a lone straight line.** A chalk `<filter>` with the default objectBoundingBox region, applied to a group whose only child is a perfectly horizontal line, rendered nothing: the bounding box has zero height. Found because `ffmpeg freezedetect` reported the first 2.875 s of candidate 1 as frozen (`technical-review/render_c1_*/freeze_black_detect.txt`); the 1 s still and candidate frames confirmed the line was missing. Fix: give the filtered group a non-zero box (a transparent rect) or use `filterUnits="userSpaceOnUse"`; verified by a re-rendered still (`out/stills_cr1b/t1_50.png`). Use: run `freezedetect` (n=-60dB, d≈0.75 s) on every full candidate; unexpected freezes point to invisible drawing.
2. **Commons helper searches need `filetype:video`.** `search --provider commons` with plain words returned 0 candidates for every beach/wave query; adding `filetype:video` to the query text returned video files (most then correctly blocked by the rights gate as BY-SA or copyrighted). Evidence: `research/search_commons_*_2026-10-28.json`.
3. **Decode previews from each MIA clip's own `videoUrl`.** A curl-loop thumbnail montage did not line up with the result order when checked against frames decoded from the clips (cause not established); frame strips from `videoUrl` were consistent with titles and later downloads. Evidence: `research/previews/mia_q02-man-woman-sand_thumbs.png` vs `research/previews/strips_q02-man-woman-sand.png`; helper scripts `research/mia_search.sh`, `research/mia_strips.sh`.
4. **Local ASR is available for timing aids.** whisper.cpp large-v3-turbo (`~/Library/Application Support/WhisperDesk/models/ggml-large-v3-turbo.bin`) runs through the user-site pywhispercpp 1.5.1 under `/usr/bin/python3` (3.9) only from a scratch copy with `from __future__ import annotations` prepended to its modules (the installed copy raises a `TypeError` on `bool | TextIO` annotations). Running both whole-file and 15 s-window passes gave word times that agreed within ~0.5 s in vocal passages; the windowed pass removed a long drift at the intro. This is estimated timing, not listening, and the transcript differed from the supplied lyrics in places.
5. **The installed GSAP skill copies still say GSAP is not installed.** `.claude/skills/gsap-*/SKILL.md` kit notes contradict `shared-animation-library/remotion-runtime/README.md` (GSAP 3.15.0 + `@remotion/gsap` 4.0.538 installed); `useGsapTimeline` worked in this song's slate scene (stills and candidate). Treat the runtime README as authoritative until the skill notes are refreshed.

Scope: these are mechanism findings; none is a visual-quality or sync claim.

## L24 — Flicker and single-frame dropouts in SVG-filtered scenes; word-level lyric timing (2026-10-29, Chalk it up)

Trigger: the user reported "flashing chalk" and lyric sync after watching a candidate. Evidence: `productions/chalk-it-up-white-wellbeing-the-spirit-of-the-west/technical-review/revision_flash_sync/` and `render_c4…c9/`.

Frame-difference series (`ffmpeg … tblend=all_mode=difference,signalstats`) on a cropped static region showed repeated spikes before static seeds and almost no change afterward.
2. **Scan every candidate for single-frame dropouts.** `blink_scan.mjs` flags frames that differ from both neighbours while the neighbours match. With the shared renderer's default 2 workers, strokes inside large SVG-filtered groups vanished for one frame (33–49 frames per render, all in one scene). The same frames rendered with `--stills` were correct. Removing a nested filter cut the count to 4. A GSAP-to-SVG entrance rewrite and a per-frame filter refresh did not remove the rest. **`--workers=1` removed them all** (0 of 4,273) and was not slower here (4 min 27 s vs about 5 min 9 s).
3. **When word-level lyric display is chosen or requested, use word-level alignment evidence.** whisper.cpp heuristic word times were about four seconds early across a verse after an instrumental gap. This supports DTW as an estimate and the signal as a cross-check for this mix; neither proves sung-word timing. Keep word-level display optional, label machine/interpolated timings as estimated until listening confirms them, and follow `claude-finished-song-animation-project/18_TEMPORAL_STABILITY_AND_WORD_TIMING.txt` plus `repository-preparation/templates/WORD_TIMING_REPORT_TEMPLATE.md`.

Run it on the complete authorized candidate, retain its JSON and render identity, then inspect flagged frames with their neighbors.
