WHY THESE CHOICES FIT THIS PROJECT
- ClaudeAnimationBase and opus-video-skills provide a direct path to stable character drawing, expressive motion, separate cue data and durable frames. Their code is MIT; project output still needs original portrait staging and the selected audio.
- Lemo provides 43 actual style guides and a shared style vocabulary. Its renderer clears temporary segments on interruption, so the material and drawing techniques are more useful here than replacing the tested recovery path.
- HyperFrames provides a useful supplied-audio map and modular composition model. Current CLI segmented recovery is documented but untested in this kit. Default 3000-frame segments are longer than a 40-second reel at 30 fps; meaningful partial recovery would require an eligible route and smaller configured segments. That extra engine work is deferred in this implementation decision.
- makevoid combines paid generation with local compositing. Its planning, acting and receipts are relevant; the supplied Suno recording remains the soundtrack. The import is source acquisition, with paid services and generated replacement music recorded as external example paths.
- Hanif has useful pure-time Node-canvas drawing and review methods. Its streamed export offers a different recovery profile, so retain the baseline durable frame export.
- Evangelion's actual LICENSE is MIT although GitHub's classifier reports an ambiguous category. Its song/font/franchise material has separate provenance. Use the verified code license and original song-specific content.
- PDoomVideo, Domenic and Austerlitz expose useful architecture but have no verified reuse license in the audited source trees. Keep their imported source in read-only study storage. Their assigned use is private source study and architecture reference; the deliverable uses separately licensed or original implementation and assets.
- The three catalogs support creative discovery. Yihui has 475 entries with 196 partial prompt flags; Athemeroy distinguishes 1,401 files, 1,119 classified yes/likely files and 168 reviewed cases. Catalog counts describe evidence units, not complete buildable films.
- Remotion's documentation describes a viable frame-based alternative, with published free terms for individuals and small teams. A second engine adds project work; retain these docs as reference within the selected route.
- The Oud-Amsterdam item's primary indexed record carries a Public Domain Mark. Its metadata supports a candidate archive shot, while the song-specific brief determines whether that location/time is useful. Playback of the exact supplied clip was not verified during this review.
