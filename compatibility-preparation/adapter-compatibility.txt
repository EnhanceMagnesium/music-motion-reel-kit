All three files were read in full. Their package.json and root LICENSE were also read.

fx.mjs exports timeWarp, shake, burstParticles, landDust, ring, flashAlpha, impactStar, comicText, floatText, afterimages, starburst and heart. It imports many helpers from core.mjs, which imports createCanvas/Path2D from @napi-rs/canvas at module evaluation. Thus fx.mjs is not directly browser-loadable despite its Canvas-compatible function bodies. film.mjs imports native Canvas plus node:child_process, fs, path and crypto; its run(F) owns frame clearing, CLI arguments, temporal supersampling, image sheets, pixel-hash checks and ffmpeg output. Do not import that harness into the browser adapter.

burstParticles dependency closure is only core.mjs clamp, rng, ellipse, line, poly, fill, stroke, at and INK. Its native-Canvas allocation, grain cache, geometry/IK, fonts and film harness are not required. Adapt this exact closure into a namespaced browser module, preserving full bodies/defaults and the complete burstParticles branches. Keeping the closure local initially avoids incorrectly unifying p5 drawing functions with Canvas functions of the same name.

R06 core rng(seed) floors and clamps the seed before Park–Miller iteration. burstParticles constructs a fresh generator with seed*977 + floor(t0*1000) on every call. Preserve both steps. R06 stroke defaults to INK #1E1612; the painted base uses PAL.ink #2B2233. They are distinct palette defaults. Parameterizing the outline color is a deliberate adapter extension requiring its own check; silently substituting the base palette is not equivalence.

ACTUAL HOST CONTRACT
Canonical exact-file candidates and near-duplicate decisions are recorded in reusable-animation-context/SOURCE_COMBINATION_DECISIONS.txt. R01 commit 0ac8bf2b31942376cb6b8c4074715595d512acd2 and R02 commit 59744a69c7b916cfbe4c4ec84006b0c2f5e2fde1.

R02 host: repository-downloads/tuzhechen2005/opus-video-skills/skills/painted-animation/template/src/core.js, composite(t).
It copies the hidden p5 WEBGL drawing canvas into the visible #out Canvas2D, draws queued letters, multiplies paper grain, returns to source-over, then invokes window.overlayHook(c,t). This existing post-grain hook is the intended adapter seam. R01 core lacks it, so the planned canonical core must retain the R02 extension. An effect here is crisp and lies over letters/grain; that placement is a visible design decision. Under-grain or behind-character effects would require another explicitly designed seam and are outside this first adapter.

The host creates its p5 canvas in setup(), uses pixelDensity(1), awaits font requests and then sets window.ready=true. renderAt(t,type,q) assigns T=t, awaits redraw(), composites, and returns a data URL from #out. renderSheet also calls composite, so an installed hook participates in both paths. Only the host owns #out and those public renderer functions.

src/timeline.js: shots([[start,fn],...]) sorts registrations; drawWorld invokes fn(t,lt,dur), using the next shot start or DUR as end. Functions paint a whole frame and must support parallel and out-of-order evaluation. CAM is cleared after the shot, so a hook must not assume CAM still describes a character's placement. toScreen(x,y,cam) can map a provided camera snapshot; LAST_CAM represents the last camera used and is not a universal shot camera.

PROPOSED SMALL ADAPTER CONTRACT
Future derived destination: shared-animation-library/adapters/r06-burst-particles.mjs, with explicit source mapping and MIT notice. A factory takes {events,seed}; an evaluation method takes {ctx,videoSeconds,width,height}. It draws into the supplied CanvasRenderingContext2D and returns no image or video. No Canvas allocation, asynchronous load, DOM dependency or global clock is needed inside the adapter.

An event has unique id, atVideoSeconds, x, y and options. x/y are native screen pixels, positive right/down. options preserve R06 meanings: n (integer count), speed (px/second), life (seconds), gravity (px/second squared), colors (nonempty CSS-color array), size (pixels), kind (spark/debris/dust/confetti/ember), seed (integer), spread and dir (radians). Upward default dir=-PI/2. Defaults remain n=14, speed=520, life=.6, gravity=900, size=8, seed=1, spread=2*PI and source default colors. For production seed plus event id, define and document a stable deterministic integer derivation; never derive it from invocation order or global p5 random state.

Validate once at construction: finite numbers, life>0, n>=0 integer, size/speed/gravity>=0, recognized kind, nonempty colors and unique ids. The original source does not validate these cases; validation is adapter-owned behavior. Avoid equal start/end intervals and nonfinite times. Reject invalid evaluations rather than letting NaN enter a Canvas transform.

Time is video-local seconds. Given source excerpt offset O, sourceSeconds=O+videoSeconds and event.atVideoSeconds=event.sourceSeconds-O when cues originate in the master. Convert exactly once in production loading. Cue evidence remains attached to the original source timestamp. For frame i at configured fps, videoSeconds=i/fps; adapter must not snap to its own fps or use R06 timeWarp. The burst remains inactive before its event and after life*1.6. Each particle's fade uses its own seeded lifetime. Final event tails may intentionally continue across shot boundaries; if a production wants shot clipping, declare a separate event validity interval instead of resetting simulation on a cut.

The first version accepts screen coordinates only. For attachment to moving world objects, the production computes anchor/camera state as a pure function of the requested time and supplies transformed position plus intended size/speed/gravity scaling. Do not use stale CAM or LAST_CAM blindly. Generic world-space simulation and occlusion are not necessary for this bounded integration.

Lifecycle: capture any existing overlayHook; install one dispatcher, with a documented ordering of existing karaoke and the particle layer, and restore the previous hook on disposal. Wrap each callback in save()/try/finally/restore(); reset transform, alpha, shadow and source-over for its own layer. Prevent duplicate installation and concurrent mutation of events. The upstream helpers restore most state, but the host does not wrap overlayHook itself; isolate the whole layer. Initialization completes before window.ready is exposed. If dynamically importing the module, include that promise in setup's existing readiness wait. For legacy classic scripts, expose one namespaced adapter object without adding conflicting global clamp, line, ellipse, ring or at declarations.

WHY THE KINETIC CANDIDATE IS A LARGER FIRST INTEGRATION
Read kinetic template reel/reel.js in full across contiguous sections, plus reel/cues.js, reel/index.html, package.json and renderer entry/readiness contract. Source: repository-downloads/tuzhechen2005/opus-video-skills/skills/kinetic-reel/template/.

reel.js is a complete engine, not an exported typography helper. It imports Three 0.160.0; reads KCUE; owns W/H=1920x1080, #out, DUR/PROJECT/ready/renderAt/renderSheet/gpuInfo; creates Canvas2D buffers and two WebGL renderers RA/RP; eagerly builds terrain, liquid, knot, cloud and post materials. Its output canvas is WebGL and cannot also be the painted host's Canvas2D output. Its frame(t) chooses SCENES/TR, swaps mutable ctx for transition buffers, freezes outgoing scene at s0-1/FPS and runs an opaque post pass. Loading both entry scripts on the host is incompatible.

Kinetic minimal typography closure is letters + dropWord + seg/clamp + expoOut and requested font/color options; it could be adapted separately later. letters uses Canvas measureText, letterSpacing, per-glyph transforms and UTF-16 string indices. dropWord's comment says overshoot, but its actual easing is expoOut, with y+(1-expoOut(k))*fall, stag=.03 and dur=.32; do not promise a spring or silently replace it with backOut. Existing host already queues crisp letters with font and camera handling, so kinetic glyph staging is useful when explicitly required by a song, but seeded five-kind particles add a more distinct capability without expanding fonts.

Whole kinetic loading requires cues.js before reel.js, local Three resolved at its relative node_modules path, required #out/scrub/tt elements, Google Fonts stylesheet and fontsReady (Anton, Archivo Black, Instrument Serif, JetBrains Mono and subset CJK Noto Sans SC). document.fonts.load completion alone is not a strong glyph-availability proof. Production text would need complete glyph coverage, missing-font handling and portrait composition. It also needs disposal for both renderers, textures, geometry and materials, which the original single-page template does not supply. Prepared kinetic dependencies are Three 0.160.0 and puppeteer-core ^25.11.0; launcher checks do not establish integrated shaders or visual correctness.

MEANINGFUL NON-RENDERING ACCEPTANCE FOR CLAUDE IMPLEMENTATION
1. Original source hashes and both canonical provenance records match; preserve full R06 MIT text. Assert browser module graph contains no @napi-rs/canvas or node: imports and no reference to global p5 randomness.
2. Evaluate original source function and browser adaptation against the same recording Canvas2D context (methods record arguments/state, gradients record stops; no pixels generated). For each of five kinds compare complete traces at event-.01, event, event+.1, event+life, event+life*1.6 and just after. Use both source defaults and nondefault options, several seeds and nonzero event times. Ensure at least one active trace contains nonzero drawable geometry. This checks actual behavior against the original, rather than testing a duplicate adapter formula alone.
3. Compare traces for time orders [late,early,middle,late] and [late] in fresh instances; same time/input has identical trace. Different seeds alter at least one active trajectory. Repeated adapter construction has no reliance on p5 randomSeed or previous frames.
4. Set sentinel Canvas transform, alpha, compositing, shadow and stroke properties; verify the layer restores them on normal completion and injected drawing failure. Verify dispatcher ordering, previous-hook restoration and duplicate-install handling. Test forwarding of actual ctx and requested t, and that the dispatcher never clears or replaces host output.
5. Test cue conversion with nonzero source offset, e.g. source 12.4, offset 10 -> local 2.4; inverse returns 12.4. Frame i uses configured fps once. Verify event onset and expiry across a shot boundary and a portrait screen coordinate without hidden 1920/1080 scaling.
6. Check invalid adapter inputs explicitly: zero/negative life, empty colors, NaN, duplicate ids and unsupported kind; ensure failures occur before partial drawing. Check zero count is a valid no-op.
7. Verify loaded asset/font paths for the canonical host and inspect complete initialization graph. Readiness checks can inspect imports, URLs and hooks without invoking setup/draw/redraw/renderAt, which generate scene pixels. Label any renderer/GPU/font-visual check deferred if it would invoke those functions.
