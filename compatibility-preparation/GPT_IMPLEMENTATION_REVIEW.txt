PRIORITY FINDINGS

P1 — Soundtrack does not follow the configured master excerpt
shared-animation-library/base/render.mjs:155–158 and60–65
Particle cues convert source time using sourceAudioOffsetSeconds, but clip audio seeks only by range start a; separate-frame encoding applies no source seek. A recording offset10 with a source cue12.4 places a visual cue at local2.4 while exporting audio from source0. Use offset plus selected local start in both export modes. Inspect actual FFmpeg arguments in non-rendering tests.

P1 — Cached frames are not bound to a production identity
shared-animation-library/base/render.mjs:53,135–145 and60–65
Every root/entry writes cwd-relative out/frames. Resume trusts any prior JPEG larger than1000bytes, and encoding reads an unbounded sequence. Another source/config/fps/dimension/range can silently reuse earlier images or retain a longer video's tail. Define a manifest tied to entry/config/source/assets and output parameters, with bounded selected indices. Reuse the existing production renderer's identity approach where suitable rather than introducing a second untracked cache convention.

P1 — A nonzero frame range cannot be encoded reliably
shared-animation-library/base/render.mjs:134–145 and60–65
At24fps, range2:4 produces f00048..f00095 while --encode has no -start_number and no selected-range metadata. Record the first frame, count, fps, local range and audio offset, then use them for sequence input and soundtrack alignment.

P2 — Clip export can report success after encoder failure
shared-animation-library/base/render.mjs:157–168
The driver prints wrote after a close event without requiring zero exit. Attach error/close handling at spawn time, propagate failure, stop feeding on failed child processes and report success only for a completed successful encode. These driver limitations are largely inherited upstream, but remain actionable in the reusable derived library.

P2 — Particle draw failures leak nested Canvas state
shared-animation-library/adapters/r06-burst-particles.mjs:17–18,30–36
shared-animation-library/adapters/overlay-dispatcher.mjs:31–32
The dispatcher restores one save; original particle helpers can leave additional saves when a real drawing operation throws. Reproduced spark stroke failure leaves depth2, alpha.8100406195 and source-over instead of sentinel depth0, alpha.3 and multiply. Make the adapter's nested saves exception-safe while recording the intentional source adaptation. Test failures inside actual spark/debris/confetti/ember paths, not only an independent failing layer.
