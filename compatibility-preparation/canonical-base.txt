Every referenced local script exists, including installed dependency files. These are ordered global scripts, not ESM exports. Reordering, injecting twice, or loading both bases creates duplicate global declarations.
config.js declares PROJECT {duration:11,bpm:120,offset:0}; core.js consumes PROJECT at load time. clawd.js uses core helpers; timeline.js defines SHOTS, shots, LOOPS, drawWorld and brushWipe; sheets.js registers model loops; demo.js registers scenes. core setup/draw callbacks call drawWorld after all scripts load.
R02 src/karaoke.js is present but NOT loaded by studio.html. To enable it, explicitly add it after core.js and before p5 setup starts; its global LY, KFONT, kLine and pun and window.EXTRA_FONTS/overlayHook must be isolated in the shared-library adapter. Empty LY means no lyric overlays.
render.mjs ESM imports puppeteer-core; node:child_process spawn; node:fs mkdirSync/writeFileSync/existsSync/statSync/renameSync/readdirSync; node:path dirname/resolve; node:url pathToFileURL; node:os homedir. It resolves studio.html and output paths against current working directory; run from a complete template root or adapt all paths explicitly.
gpu_probe.mjs imports puppeteer-core and launches external Chrome; it is optional diagnostic tooling, not a scene dependency.
External dependencies: separately installed Chrome/Chromium executable, ffmpeg for clip/encode, and Google Fonts network font CSS. Puppeteer-core does not bundle a browser. Core awaits font load and assumes browser document/canvas/WebGL/p5 globals.

PUBLIC / ADAPTER CONTRACT
Scene API: shots([[startSeconds, fn], ...]); fn(t, localTime, shotDuration) paints a whole frame and must derive state from time. LOOPS[name](t), LOOPS[name].len and window.LOOP select standalone loops.
Renderer API: window.ready; window.renderAt(t,type=image/png,q=.92) -> Promise<dataURL>; window.renderSheet(times,cols=3,w=640,crop=null,at=null) -> Promise<{url,ms[]}>; window.gpuInfo() -> string. renderSheet at string values are evaluated in page scope; shared adapters should accept validated numeric values instead of exposing arbitrary string evaluation.
Core timing/geometry/paint API: clamp, lerp, ease, easeOut, backOut, hash, bpOf, jit, boilSeed, seg, frac, beatN, pulse, pulse2, wob, easeIn, elasticOut, kf, mixCol, shakeXY, spring, ring, onTwos, arcPt, jump, take, stroll, camBegin, camEnd, toScreen, flash, glow, irisShape, iris, rectPts, ellPts, rrPts, starPts, through, ribbon, centred, paint, paintAt, inkLine, letter, sfx, flushBrush, flushLetters.
Character API: spinView, turn, tintCols, clawd, lunchbox, smearTrail, gloom, blush, eyes, eye, mouth, hat, faceHat, emote, heartPts, feel, emotions, move, dancer. These share VIEWS/TINT/EMOTE_TOP/EMO and core PAL/BOILN/CLAWD_N globals.
R02 additional extension API: window.EXTRA_FONTS array of [fontDescriptor,text]; window.overlayHook(ctx,t) called after grain compositing, above the grain. Only a single overlayHook slot exists; combine multiple overlays in one controlled dispatcher.

COMPATIBILITY LIMITATIONS
Fixed 1920x1080 landscape canvas, W/H and karaoke layout hard-coded. Portrait or arbitrary resolution requires an explicit layout adapter and validation. Default p5.brush scaleBrushes(5), WebGL and blending behavior are renderer assumptions.
Timing constants derive from PROJECT once; changing PROJECT after core.js loads does not recompute BPM/BEAT/OFF/DUR. fps=24 is driver default; BOIL=12 and onTwos use 12 Hz. Determinism requires boilSeed per independent element and pure scene functions because renderer supports parallel and out-of-order requests.
Paint wrapper centres each shape to work around p5.brush 2.2.3 zoom-related lost strokes; retaining the wrapper is part of compatibility.
Fonts can vary or fall back if network font loading fails; R02 awaits Permanent Marker, Shantell Sans and requested EXTRA_FONTS, but its CSS also lists Ma Shan Zheng. Optional karaoke requests that family when enabled. Runtime fonts should be locally staged with explicit provenance if reliable offline visuals are required.
HTML out/scrub/tt elements and the hidden p5Canvas are part of the current renderer contract. browser APIs cannot be imported directly in Node without a host.
MIT LICENSE files are byte-identical; preserve license text and separate upstream provenance for R01 and R02.
R02 README references absent docs/emotions.webp; static documentation link is incomplete even though runtime code graph is complete. Restore the exact upstream file only in a derived package if retaining that README link.
