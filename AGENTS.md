# Local project guidance

Read `PROJECT_INSTRUCTIONS.md` before production work. For a Codex Local standalone production, use `CODEX_LOCAL_FULL_SONG_PRODUCTION_PROMPT.txt`; that prompt is Codex's execution contract. Do not route Codex work through Claude's launch prompt, runbook, or app procedures. For a Claude Project production, use `claude-finished-song-animation-project/05_NEW_SONG_CONVERSATION_PROMPT.txt`. Follow the applicable shared subject guides, especially 07 (quality review), 10 (Moving Image Archive), 11 (headless frame review), 12 (Skillry), 13 (repository navigation), 14 (HyperFrames) and 15 (Commons/Internet Archive). In guides 07 and 11, the Browser-pane companion-review subsection is Claude Desktop only; Codex follows the shared Playwright/FFmpeg steps and its own available local playback tools. Read `repository-preparation/REPOSITORY_NAVIGATION_AND_USE_GUIDE.md` and both shared animation-library READMEs before implementing a Remotion production.

For a Cursor Local production, use `CURSOR_LOCAL_FULL_SONG_PRODUCTION_PROMPT.md` and `repository-preparation/CURSOR_GROKBOT_COMPATIBILITY_GUIDE_2026-10-30.md`. Cursor reads the root `AGENTS.md` and project skills, including `.agents/skills/`; the dedicated prompt supplies the Cursor-specific local execution route. Grok Bot is a separate assistant, cloud by default. Its local-computer permission is not implied by opening this kit in Cursor.

Keep song-specific work in its named `productions/<song>/` folder. Treat shared renderer code, installed packages, pinned repositories and reference material as read-only during a song comparison.

KIT EDIT LOG: When Codex or Claude changes the reusable kit itself—its instructions, shared tools, templates, source maps or reusable workflow—add a short dated entry to `repository-preparation/CHECKPOINT.md` saying what changed, why, which files, what was checked, what remains and the next kit edit. When a task only uses the kit to make or review a song, record it in that song's `productions/<song>/CHECKPOINT.md` instead.

MOTION RESOURCES: R14–R16 are initialized in `repository-downloads/` with project-local Claude/Codex skill copies. Assess all three against each song's scene needs before storyboard lock; adopting a technique remains selective. Follow `claude-finished-song-animation-project/17_FOOTAGE_FRAME_FOOTPRINT_AND_CODE_ACTION.txt` and `repository-preparation/ANIMATION_AGENT_SKILL_RESOURCES_GUIDE.md`. The skills do not add a renderer or shared runtime dependency.

FONT DISCOVERY: Follow `claude-finished-song-animation-project/20_FONT_DISCOVERY_AND_LYRIC_TYPOGRAPHY.txt` for song-specific typography and font provenance.
